# Алгоритмы на графах
## Сеть больниц и медицинских пунктов

###  Описание проекта

Данный проект представляет собой Windows Forms приложение на C#, разработанное в рамках единого проекта лабораторных работ №4–6 по дисциплине **«Алгоритмизация и программирование»** (направление «Искусственный интеллект», 1 курс).

Программа моделирует сеть медицинских учреждений, где:
- **Вершины графа** — больницы, поликлиники и медпункты
- **Рёбра графа** — маршруты передвижения машин скорой помощи
- **Веса рёбер** — время в пути (в минутах)

Проект реализует классические алгоритмы теории графов, проводит анализ структуры сети и визуализирует результаты. Бизнес-логика вынесена в отдельную библиотеку `Lab456.Core`, интерфейс отделён от вычислений, проект покрыт модульными тестами.

###  Функциональность

####  Лабораторная работа №4: Построение графа. Алгоритмы обхода
| Задача | Описание |
|--------|----------|
| **Загрузка графа** | Чтение данных из `.txt`/`.csv` файла (формат: `Вершина1 Вершина2 Вес`) |
| **Список смежности** | Хранение графа в памяти с поддержкой взвешенных рёбер |
| **BFS (обход в ширину)** | Поуровневый обход с использованием очереди, вывод порядка посещения |
| **DFS (обход в глубину)** | Рекурсивный обход с использованием стека, вывод порядка посещения |
| **Проверка достижимости** | Определение, достижима ли вершина B из вершины A |
| **Компоненты связности** | Поиск и вывод всех компонент связности неориентированного графа |

####  Лабораторная работа №5: Взвешенный граф. Алгоритм Дейкстры
| Задача | Описание |
|--------|----------|
| **Взвешенные рёбра** | Поддержка весов (время в минутах) при загрузке графа |
| **Алгоритм Дейкстры** | Реализация «жадного» алгоритма поиска кратчайших путей без библиотечных функций |
| **Таблица расстояний** | Вывод кратчайшего расстояния от стартовой вершины до всех остальных |
| **Восстановление пути** | Построение и отображение цепочки вершин маршрута |
| **Поиск маршрута** | Нахождение оптимального пути между двумя вершинами, заданными пользователем |
| **Анализ сложности** | Обоснование временной сложности O((V+E) log V) с использованием PriorityQueue |

####  Лабораторная работа №6: Дополнительный анализ графа
| Задача | Описание |
|--------|----------|
| **Точки сочленения** | Поиск вершин, удаление которых разрывает граф (алгоритм Тарьяна) |
| **Минимальное остовное дерево** | Построение МОД алгоритмом Прима, вывод рёбер и суммарного веса |
| **Задача варианта 17** |  **Поиск ближайшей больницы**: нахождение медицинского учреждения с минимальным временем доставки от заданной точки |

####  Итоговый проект: Анализ и сравнение
| Задача | Описание |
|--------|----------|
| **Графический интерфейс** | Удобное меню с вкладками для каждой операции, поля ввода и вывода результатов |
| **Замер времени** | Использование `System.Diagnostics.Stopwatch` для измерения производительности алгоритмов |
| **Сравнение BFS и Дейкстры** | Демонстрация различий: BFS находит путь с минимальным числом рёбер, Дейкстра — с минимальным весом |
| **Эксперимент** | Тестирование на графах размером 30–50 вершин, анализ роста времени выполнения |
| **Визуализация графа** | Отрисовка графа на панели с цветовой кодировкой: больницы (синий), путь (красный), МОД (зелёный), точки сочленения (красный) |

###  Использование приложения

При запуске открывается окно с **пятью вкладками**:

####  Вкладка 1: Загрузка графа
1. В поле **«Файл графа»** укажите путь к файлу (по умолчанию: `graph.txt`)
2. Нажмите **«Загрузить»** или **«Обзор...»** для выбора файла
3. Статус покажет количество загруженных вершин и рёбер
4. Граф отобразится на панели внизу (вершины по сетке, рёбра — линии)
5.  Опция **«Показать веса рёбер»** включает отображение чисел на рёбрах

####  Вкладка 2: ЛР 4 — Обход графа
1. Введите **стартовую вершину** (например: `Central_Hospital`)
2. (Опционально) Введите **целевую вершину** для проверки достижимости
3. Нажмите **«Запустить BFS/DFS»**
4. Результаты:
   - Порядок обхода BFS и DFS
   - Ответ о достижимости целевой вершины
   - Список компонент связности
   -  Время выполнения каждого алгоритма
5. На панели графа подсветится путь обхода (оранжевый)

####  Вкладка 3: ЛР 5 — Алгоритм Дейкстры
1. Введите **стартовую** и **целевую вершины**
2. Нажмите **«Запустить Дейкстру»**
3. Результаты:
   - Таблица кратчайших расстояний до всех вершин
   - Маршрут до целевой вершины с суммарным весом
   - Время выполнения
4. На панели графа подсветится кратчайший путь (красный)

####  Вкладка 4: ЛР 6 — Анализ графа
1. Нажмите **«Анализ (Точки/МОД)»**
2. Результаты:
   - Список точек сочленения с пояснением их роли
   - Рёбра минимального остовного дерева и его суммарный вес
   -  **Задача варианта 17**: ввод местоположения и списка больниц → вывод ближайшей больницы, времени и маршрута
3. На панели графа:
   - Точки сочленения — красный цвет
   - Рёбра МОД — зелёные жирные линии

####  Вкладка 5: Сравнение алгоритмов
1. Введите **стартовую** и **целевую вершины**
2. Нажмите **«Сравнить алгоритмы»**
3. Результаты в таблице `DataGridView`:

| Алгоритм | Время (мс) | Результат | Найденный путь |
|----------|-----------|-----------|----------------|
| BFS | 2 | 5 переходов | A → B → C → D |
| Дейкстра | 3 | Вес: 12 мин | A → E → D |

###  Обработка ошибок

Приложение включает многоуровневую валидацию:

| Ошибка | Обработка |
|--------|-----------|
| Файл не найден | `MessageBox` с текстом ошибки, статус « Ошибка загрузки» |
| Неверный формат строки | Пропуск строки с предупреждением в консоль |
| Отрицательный вес ребра | Исключение с сообщением о недопустимом весе |
| Вершина не существует в графе | Предупреждение с подсказкой доступных вершин |
| Граф пуст или недостаточно вершин/рёбер | Исключение с требованием минимум 15 вершин и 20 рёбер |
| Попытка запуска без загрузки графа | `MessageBox` с напоминанием загрузить граф |

**Архитектурная защита**: методы валидации и загрузки вынесены в библиотеку `Lab456.Core`, что предотвращает дублирование кода и обеспечивает повторное использование.

###  Анализ сложности алгоритмов

| Алгоритм | Временная сложность | Пространственная сложность | Применимость |
|----------|-------------------|--------------------------|--------------|
| **BFS** | O(V + E) | O(V) | Кратчайший путь по числу рёбер, проверка связности |
| **DFS** | O(V + E) | O(V) | Поиск циклов, топологическая сортировка, компоненты связности |
| **Дейкстра** | O((V+E) log V)* | O(V) | Кратчайший путь по весу (неотрицательные рёбра) |
| **Точки сочленения** | O(V + E) | O(V) | Анализ устойчивости сети |
| **Прим (МОД)** | O((V+E) log V)* | O(V) | Построение минимальной инфраструктуры |

\* При использовании `PriorityQueue`
